# Pokemon Battle System (Java)

Projeto desenvolvido em Java aplicando os principais pilares de POO:

- Herança
- Classe Abstrata
- Interface
- Encapsulamento
- Polimorfismo

O sistema simula batalhas entre Pokémons com tipos, golpes e cálculo de efetividade.

Desenvolvido no IntelliJ IDEA.

## Quality Gate
Se ha configurado un Quality Gate con GitHub Actions para asegurar un mínimo de 85% de cobertura en los Pull Requests.
